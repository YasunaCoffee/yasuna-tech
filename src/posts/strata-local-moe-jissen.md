こんにちは！yasunaです！

今回は、**「RTX 3080 Ti＋RAM 32GBのPCでQwen3.6-35B-A3Bが45.6 tok/sで動いて、スマホから日本語で使えるところまで行けた」** という話です。

そこにたどり着くまでに、最初はコード特化のCoderというモデルを入れて、速いけど日本語がボロボロ、という寄り道もしています。2日がかりでした。

最新のGPUじゃなくても、2世代前の3080 Tiでここまで動きます。手元に少し古いゲーミングPCがある人には、けっこう夢のある話だと思います。

作業はほぼ全部 Claude Code にやってもらいました。わたしは「これやりたい」と言って、ドライバーを入れたりPowerShellを開いたりする係です。

# はじめに：Strataってなに

[Strata](https://github.com/Niko1221/Strata) は、MoE（Mixture of Experts）のモデルを**GPUとCPU、さらにSSDにまで分けて**動かす推論エンジンです。

MoEは、全体はめちゃくちゃ大きいけど、1トークンごとに使う「エキスパート」はその一部だけ、という作りです。なので、よく使うところはGPUに、残りのエキスパートはRAMに、RAMにも入りきらない分はSSDから読みながら動かす、ということができます。VRAMが16GBしかない家のPCでも、100B超えのモデルが「遅いけど動く」くらいにはなる、というのが売りです。

コマンドもかなりやさしくて、だいたいこれだけです。

```bash
strata launch --family qwen36 --model UD-Q4_K_XL
```

モデルのダウンロードも、GPUに合うエンジン選びも、起動も、全部これがやってくれます。

# 試したPC

| 項目 | 内容 |
|---|---|
| OS | Windows |
| CPU | Core i9-12950HX（16コア） |
| RAM | 32GB |
| GPU | RTX 3080 Ti Laptop（VRAM 16GB） |

RAM 32GBなのがポイントです。Strataの看板のQwen3.8-Flash-Nextは、標準的な量子化だとRAMが44GBくらい欲しいので、32GBはぎりぎり足りない側です。

# モデル選び

RAM 32GB＋VRAM 16GBで現実的なのは、この2つでした。

| モデル | 特徴 |
|---|---|
| **Qwen3.6-35B-A3B（UD-Q4_K_XL）** | 22.9GB。汎用で日本語も無難 |
| Qwen3.8-Flash-Next Coder（IQ1_M） | 125BのQwen3.8-Flash-Nextから、各層512個のエキスパートのうちコード向けの256個だけを残した版。58GBあるので、RAMに入らない分はSSDから読む（低RAMモード） |

最終的にメインにしたのは **Qwen3.6-35B-A3B** です。ただ、最初は「せっかくなので大きいほう」とCoderを選んでいて、公式ドキュメントの「コード以外や多言語では弱い」があとで効いてきます。その話は後半で。

# 入れるまでのハマりどころ

モデルに関係なく、ここでつまずきました。

## ハマり1：Claudeアプリの中からインストールすると、隔離フォルダに入る

Claude Code（Windowsのデスクトップアプリ）にインストールまでやってもらったら、普通のPowerShellで `strata` が見つかりません。

原因は、**アプリの中で実行したコマンドのファイルが、アプリ専用の隔離フォルダ**（`...\Packages\Claude_xxxx\LocalCache\...`）に置き換えられることでした。PATHには本来の場所（`%LOCALAPPDATA%\Strata`）が足されるのに、実物はそこにない、というややこしい状態です。しかもパスが長くなりすぎて、モデルの準備中に「ファイルが見つからない」で止まっていました。

なので、**インストールと起動は自分のPowerShellで**やることにしました。Claude Code には、起動したサーバーにテストを投げたり、設定を見たりする側に回ってもらいます。

```powershell
irm https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex
```

## ハマり2：NVIDIAドライバーが古い

次は「このPCに合うエンジンがない」と言われました。ドライバーが **566.07** で、Windows用のエンジンはこれに対応していなかったからです。

| エンジン | 必要なドライバー |
|---|---|
| CUDA 12版 | 576.02 以上 |
| CUDA 13版 | 580.65 以上 |

NVIDIAのサイトからRTX 3080 Ti Laptop用のドライバーを入れて、**621.01** に上げたら通りました。GeForce Experience に古い Nsight まで入っていて、このPCのNVIDIAまわりの年季を感じました。

## ハマり3：考える時間が長すぎて、本文が空になる

最初にCoderで `max_tokens: 800` にして試したら、**800トークン全部を考える部分に使い切って、本文が空**でした。どちらのモデルも「考えてから答える」タイプで、簡単なお題でもかなり考えます。

Strataには、接続するアプリ全部に効く「Chat settings」があるので、`max_tokens` を省略したときの上限を **4000** にしました。これで、省略しても最後まで答えが返るようになりました。

# Qwen3.6-35B-A3Bを動かす

ダウンロードは約23GBで、コンテキストは32Kです。

## 日本語で「重複を消す関数」を頼む

お題は「Pythonでリストから重複を取り除き、順序を保つ方法を日本語で簡潔に説明して、コード例も付けて」です。

| 項目 | 値 |
|---|---|
| 生成速度 | **45.6 tok/s** |
| 出力 | 1,057トークン、24秒 |
| 日本語 | 崩れなし |

「`dict.fromkeys()` を使うのがいちばん簡潔」という説明が、ちゃんとした日本語で返ってきました。

ただ、1か所だけ間違いもありました。「ハッシュできない要素が入っているときはこちら」として出してきた `seen = set()` のコードも、結局ハッシュできる要素でしか動きません。細かいところはたまに外す、くらいに思っておくのがよさそうです。

# スマホのOpenCodeから使えるようにする

ここからが本題です。家のPCで動いているモデルを、**外からスマホで**使いたい。

## 構成

```
スマホ（Tailscale + OpenCode Mobile）
   │ Tailscaleの中だけ（HTTPS）
   ▼
3080 TiのPC: tailscale serve → opencode serve (127.0.0.1:4096) → Strata (127.0.0.1:8080)
```

外に出すのはOpenCodeだけで、それもTailscaleの中からしか開けません。StrataはPCの中だけで待っています。

1. Strataには `strata connect opencode` という、OpenCode用の設定を書き出す機能がありました。これを元に `~/.config/opencode/opencode.json` を作ります
2. PCとスマホにTailscaleを入れて同じアカウントでログイン
3. `tailscale serve --bg 4096` で、tailnetの中にだけ `https://<PC名>.<tailnet>.ts.net` を公開
4. OpenCodeをパスワード付きで起動

```powershell
cd C:\Users\<自分>\dev; $env:OPENCODE_SERVER_PASSWORD="好きなパスワード"; opencode serve
```

5. Androidの **OpenCode Mobile**（非公式アプリ）にURL・ユーザー名 `opencode`・パスワードを入れる
6. アプリの `/models` で **Qwen3.6-35B-A3B (local)**（`strata/qwen36`）を選ぶ

認証はベーシック認証ですが、`tailscale serve` のHTTPSの中を通るので、中身は見えません。そもそも自分の端末からしか届かないので、パスワードは念のための二重ロックです。

OpenCodeの送り方でStrataが動くかは、`strata connect opencode --check` で確かめられます。

```text
PASS prompt: It answered: 'pong'. (5 s)
PASS tool call: It called get_weather with {"city": "Paris"}. (6 s)
```

会話もツール呼び出しも通りました。

## ハマり4：`opencode` と `opencode serve` は別物

最初、URLを開いたら **502** でした。

調べたら、わたしが起動していたのは引数なしの `opencode`、つまり**PCの画面で使うターミナル版（TUI）**で、外からの接続を待つサーバーではありませんでした。Ctrl+Cで止めて `opencode serve` で起動し直したら、ちゃんと401（パスワードを聞かれる）が返るようになりました。

## スマホから「宇宙と愛の話をして」

つながったので、スマホから「宇宙と愛の話をして」と頼んでみました。

![OpenCode Mobileの画面。「宇宙と愛の話をして」という入力に、ビッグバンや星の元素、愛と宇宙の複雑さの話が日本語で返ってきている。下のモデル欄はQwen3.6-35B-A3B (local)](/img/strata-opencode-mobile-qwen36.png)

ふつうの日本語で、しかもちょっとエモい話が返ってきました。家のPCで動いているモデルが、外のスマホでこれを書いてくれるのはかなりうれしいです！

ちなみに、カール・セーガンは物理学者というより天文学者ですし、この引用が本人の言葉どおりかも確かめていません。雑談としては楽しいけど、事実の話はうのみにしないほうがよさそうです。

## 最初の返事が遅いのは、タイトル付けのせい

スマホから最初にリクエストを送ったときは、返事まで約100秒かかりました。PCのログを見ると、届いていたリクエストは2つです。

| 順番 | 中身 | かかった時間 |
|---|---|---|
| ① | OpenCodeが会話のタイトルを付けるリクエスト（入力554トークン） | 86秒 |
| ② | 本題（入力7,892トークン。システムプロンプトとツールの説明込み） | 17秒 |

本題は17秒で終わっていて、待たされていたのは先に走ったタイトル付けのほうでした。タイトルを付けるだけなのに考える部分に約1,400トークン使っていて、しかも最初の約63秒は入力の読み込みが止まっていました。止まっていた原因は、まだ分かっていません。

本題のほうも、OpenCodeは毎回システムプロンプトとツールの説明で約7,400トークン読むので、1回目の返事は少し待ちます。

## スリープ対策

電源設定を見たら、放っておいてもスリープしない設定にもともとなっていました。気をつけるのは**ふたを閉じたとき**だけで、Windowsの初期設定は「スリープ」なので「何もしない」に変えます。

```powershell
powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /setactive SCHEME_CURRENT
```

Strataが動いている間はGPUもCPUもかなり熱くなるので、ふたを閉じるなら電源につないで風通しのいいところに置くのがよさそうです。

# 寄り道：最初はCoderにしていた

ここからは、Qwen3.6の前に試したCoderの話です。

## 速さは十分

Coderは、125BのQwen3.8-Flash-Nextから、コード向けのエキスパートだけを半分残した版です。約64GBのダウンロードのあと、無事に起動しました。お題は「n番目の素数を効率よく返すPython関数を書いて」です。

| 項目 | 値 |
|---|---|
| 生成速度 | **39.3 tok/s** |
| 出力 | 3,622トークン（うち約2/3が「考える」部分）、92秒 |
| 先読み（MTP）の当たり率 | 75% |
| VRAM | 14.7GB / 16GB |
| コンテキスト | 64K |

返ってきたのは、エラトステネスのふるいを区間ごとに分けて計算する、ちゃんとした実装でした。公式の実測（RTX 5070＋RAM 64GBで約55 tok/s）よりは遅いけど、3080 Ti＋RAM 32GBでこの速さなら十分です。

さらに速くしたいときは、自動チューニングがあります。設定を1つずつ変えて測って、誤差より大きく速くなったものだけプリセットとして保存してくれます（約20分）。

```bash
strata tune auto launch-iq1_m-64k --use coding
```

## でも日本語がダメ

スマホから使えるようにして、さっそく「日本語で答えて」と指示してみました。

コードは正しく書けます（順番を保ったまま重複を消す関数）。でも説明の日本語が、

> `seen` 記保存重複をの already seenををの

みたいに崩れて、後半は英語に戻ってしまいました。公式の「コード以外や多言語では弱い」のとおりです。

これを見て、思わずこうつぶやいていました。

<blockquote class="twitter-tweet" data-lang="ja"><p lang="ja" dir="ltr">Coderさんはほぼ英語しか話せないので英語覚えようかなという気持ちになる。逆に制約あるローカルLLMに人間が合わせにいくのもまた粋まであるのか(？)</p>&mdash; yasuna (@yasun_ai) <a href="https://twitter.com/yasun_ai/status/2116461035079303446">このポストを見る</a></blockquote>

クラウドの大きいモデルなら、こっちが何語で話しても合わせてくれます。でも手元のローカルLLMには、得意なこととできないことがはっきりあります。だったら人間のほうが少し歩み寄って英語で話しかける、というのも、自分のPCで自分のモデルを飼っている感じがしてちょっと楽しいんですよね。

とはいえ、毎回英語で頼むのはさすがに疲れそう、ということで、次の日にQwen3.6-35B-A3Bを入れたのでした。

## 2つを並べると

| | Qwen3.6-35B-A3B | Coder |
|---|---|---|
| 生成速度 | 45.6 tok/s | 39.3 tok/s |
| 日本語 | 崩れなし | 崩れる |
| コンテキスト | 32K | 64K |
| ダウンロード | 約23GB | 約64GB |

お題がちがうので速さはざっくりの比較ですが、同じPCで、Qwen3.6のほうが速くて日本語も通じます。ふだん使いはQwen3.6がよさそうです。

# これから：司令役＋Coder、をやりたいけど

日本語で会話して計画を立てる「司令役」のモデルを置いて、Coderはコードを書くサブエージェントにする構成を考えています。OpenCodeはエージェントごとに使うモデルを分けられるので、設定ファイルだけで組めます。

```
スマホ (OpenCode Mobile)
   ▼ Tailscale
3080 TiのPC: OpenCode サーバー
   ├─ メインのエージェント（日本語で会話・計画・まとめ） → 司令役のモデル
   └─ サブエージェント「coder」（コードを書く）         → Strata Coder
```

日本語が崩れないので、条件だけ見ればQwen3.6は司令役の候補になります。

ただ、Strataが一度に動かせるモデルは1つだけです。OpenCodeでどのモデル名を選んでも、答えるのはStrataにいま読み込まれているモデルで、Coderに戻すにはStrataを起動し直すことになります。同じPCで司令役とCoderを同時に動かすには、もうひと工夫いりそうです。

# おまけ：0.2.9が来た

途中で Strata 0.2.9 が出ていました。速くなったのはLinux＋NVIDIA、Strix Halo、Intel Arc、DGX Sparkで、**Windows＋NVIDIAの速度は変わらず**。でも、OpenCodeで使うのに効く直しが入っていました。

- 回答の中のコードブロックに書いたツール呼び出しの例を、誤って実行しなくなった
- エージェントの会話の途中で、ツール呼び出しがただの文字として返ってくる問題が直った

# まとめ

- **3080 Ti＋RAM 32GBで、Qwen3.6-35B-A3Bが45.6 tok/sで動く。日本語も崩れない。** Strataのコマンド1本でダウンロードからエンジン選びまでやってくれる
- **インストールと起動は、Claudeアプリの外の普通のPowerShellで。** アプリ内だと隔離フォルダに入ってしまう
- **考えるモデルは `max_tokens` を大きめに。** 小さいと考えている途中で切れて本文が空になる
- **スマホから使うなら Tailscale＋`opencode serve`（TUIの `opencode` ではない）＋OpenCode Mobile。** `strata connect opencode --check` で接続テストまでできる。最初の返事が遅いのは、OpenCodeのタイトル付けが先に走るから
- **Coder（Flash-Nextのエキスパート半分版）は39.3 tok/sで速いけど、日本語が崩れる。** ふだん使いはQwen3.6

次は、司令役とCoderをどう同時に動かすかを考えて、スマホから日本語で頼むとCoderが裏でコードを書く、という形まで持っていきたいです。

それでは！
